Totally—let’s make this dead simple, one step at a time, no env vars lingering, and with files where the verifier expects them.

**Assumptions**

* Run these from your repo **root**.
* Server is running at `http://localhost:8080`.
* The server wrote `public/u16_server_key.bin` on boot (it does in your `App.kt`).

---

# 0) Make a tidy spot

```bash
mkdir -p verifier
```

---

# 1) Generate a private voter receipt (local)

This creates a receipt ciphertext + a private client key (for this voter only).

```bash
./gradlew :verifier:run --args="receipt-gen --candidate=2 --out=verifier/receipt.json"
```

Peek at it:

```bash
jq . verifier/receipt.json
```

You’ll see fields `ciphertextB64` and `clientKeyPath` (something like `receipts/1724..._u16_client_key.bin`).

---

# 2) Cast the vote (attach your receipt to the vote)

Create the request body in a file (all inline, no shell vars). Replace the ID/name/address/age if you want.

```bash
jq -n --arg rc "$(jq -r .ciphertextB64 verifier/receipt.json)" \
  '{
     id:"u12345-test",
     name:"Alice Example",
     address:"123 Main St",
     age:34,
     candidate:2,
     receiptCtB64:$rc
   }' > verifier/vote.json
```

Send it:

```bash
curl -sSf http://localhost:8080/vote \
  -H 'Content-Type: application/json' \
  -d @verifier/vote.json \
  | tee verifier/cast_response.json
```

You should see `{"ok":true,"candidate":2,"recordId":"u12345-test"}`.

---

# 3) Confirm your record is on-chain

```bash
curl -sS http://localhost:8080/blocks \
  | jq '.[] | .records[] | select(.id=="u12345-test")'
```

You should see the summary row for your ID.

---

# 4) Fetch your stored receipt and decrypt it (proves your choice)

Get the stored receipt from the server:

```bash
curl -sS http://localhost:8080/receipt/u12345-test \
  | jq -r .receiptCtB64 > verifier/stored_receipt.txt
```

Decrypt it with **your** private key (path was printed in step 1 and is in `verifier/receipt.json`):

```bash
./gradlew :verifier:run --args="receipt-decrypt --key=$(jq -r .clientKeyPath verifier/receipt.json) --ct=$(cat verifier/stored_receipt.txt)"
```

Expected output:

```
Decrypted receipt → candidate 2
```

---

# 5) (Optional) Fold all ballots and write encrypted totals

Save the encrypted one-hot ballots:

```bash
curl -sSf http://localhost:8080/user-votes \
  -H 'Accept: application/json' \
  -o verifier/encrypted_user_votes.json
```

(Optionally save blocks for ID→row mapping):

```bash
curl -sSf http://localhost:8080/blocks -o verifier/blocks.json
```

Fold (explicitly point at files so nothing “goes missing”):

```bash
./gradlew :verifier:run --args="fold --server-key=public/u16_server_key.bin --votes=verifier/encrypted_user_votes.json --blocks=verifier/blocks.json --id=u12345-test"
```

This writes `u16_tally_ciphertexts.json` in the current directory. If a dev client key is discoverable, it’ll also print plaintext tallies and write `verified_vote.json`.

---

## If you hit “cannot find files”

* Always run `./gradlew :verifier:run ...` from the **repo root**.
* Use **absolute-ish** paths in args like we did (`--server-key=public/u16_server_key.bin`, `--votes=verifier/encrypted_user_votes.json`, etc.).
* Make sure the server actually wrote `public/u16_server_key.bin`. If not, pull it explicitly:

  ```bash
  curl -sSf http://localhost:8080/server-key -o public/u16_server_key.bin
  ```

That’s it—each step is standalone, no shell vars left around, and everything lands under `verifier/` so it’s easy to reason about.
